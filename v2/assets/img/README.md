# Foto do hero

Coloque aqui um arquivo chamado **`alison.jpg`** (retrato profissional, de preferência vertical ~4:5).

O site aplica filtro preto & branco automaticamente. Enquanto o arquivo não existir, aparece um placeholder.

Formatos: `.jpg` (o `index.html` aponta para `assets/img/alison.jpg`). Para usar `.png`/`.webp`, troque o `src` no `index.html`.
